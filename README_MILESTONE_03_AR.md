# LAST LECTURE — Milestone 03 / Run from the first moment

## إصلاحان طلبتهما
1. ملفات `unarmed_run_00..05.png` لم تكن موجودة في M02، لذلك الجري قبل الحصول على Debug Blade لم يعرض أي حركة أرجل. وفّرنا الملفات الستة، والأهم أن `player.gd` و`warden_run_review.gd` الآن يقرآن دورة `run_00..05.png` نفسها، قبل وبعد السلاح. ليست نسختين مختلفتين من البطل.
2. عدّلنا **نسب وقفة Idle الهادئة** لتقارب جري M02: طول الرسم وأرضية القدمين ومكان رأس الفانوس. ارتفاع الرسم في الخامتين يبدأ حول y=171 وينتهي عند y=456، والنقطة المرجعية واحدة. الغمد باقٍ بعد التقاط السيف والسيف لا يظهر في اليد أثناء الجري. وقفة Idle الأساسية ما تزال معتمدة، لكن الرسم الأصلي والجري منشؤهما صورتان مختلفتان، ولا نزعم أنهما لوحة مرسومة يدويًا من أصل موحد.

## التجربة
- فك ZIP إلى مجلد جديد، Godot 4.7 > Import > `project.godot`.
- F5: من أول بداية اللعبة **قبل السلاح** امشِ يمينًا ويسارًا، تأكد من الركض، ثم التقط Debug Blade وكرر الركض.
- افتح `scenes/warden_run_review.tscn` ثم F6: الأسهُم للحركة، B للتبديل بين حالة السيف، 1/2/3 للحجم، F للاتجاه.
- القفز والضرب ما زالت صور V4 المؤقتة؛ هذا تحديث إصلاح الوقوف/الجري فقط. لم نغير الأعداء ولا المراحل ولا البوس.

## فحوص
- تحققنا من وجود إطارات الركض الستة، ومن تماثل صور الركض قبل وبعد السيف (بصمة بايتية متطابقة)، ومن مرجعها في الأكواد والمشهد، وشفافية PNG والـZIP.
- **لم يجر تشغيل Godot التفاعلي هنا** (محرك Godot غير مثبت). يرجى اختبار F5 على جهازك قبل اعتماد نهائي.
