# LAST LECTURE — Milestone 02 / Smooth Idle + Run — Godot 4.7

## ماذا تغيّر؟
- **حافظنا على** وقفة البطل المعتمدة ونظام إخفاء Debug Blade في الغمد بعد التقاطه. سيف غير موجود قبل التقاطه.
- **تحسين التنعيم**: تنظيف الحواف واللون المتسرب، ثم تفعيل linear + mipmaps على AnimatedSprite2D لتخفيف الحواف المحبّبة عند التصغير. لا يعيد هذا إنشاء تفاصيل غير موجودة في المصدر.
- **دورة جري جديدة من 6 وضعيات مصوّرة** للهوية نفسها (الفانوس والعباءة السوداء والعاجية)، بدل رجوع V4 المؤقت. قصّ الإطارات وفصلها من لوح الرسم ومراجعتها؛ لم تتم إعادة رسم كل إطار يدويًا بصورة مستقلة.
- التخلص من قطع العباءة والأقدام المنفصلة في صور الجري. نقطة الرسم المرجعية موحّدة، وحجم الجسم متماثل، والجري 13 FPS.
- إعادة توجيه لحظة الهبوط القصيرة إلى الـIdle أو الـRun المعتمدين حتى لا ترجع رسوم V4 للحظة عند الوقوف.
- **لم نعدّل** تصميم أعداء المرحلة أو البوس أو منطق القتال.

## كيف تجرب؟
1. استخرج ZIP في مجلد جديد؛ استخدم Godot 4.7 → Import → `project.godot`.
2. افتح **`scenes/warden_run_review.tscn`** واضغط **F6** لاختبار الوقفة والجري والحجم والوجه.
3. استخدم الأسهم يمين/يسار للجري، `F` لقلب الاتجاه، `B` لتبديل امتلاك السيف، `1`/`2`/`3` للأحجام و`Space` لتثبيت الفريم الحالي.
4. استخدم F5 للعب المرحلة الحالية وملاحظة الانتقال الحقيقي من الوقوف إلى الركض.
