# بيئة حارس الجرس — M24

تُجهّز هذه الإضافة مشغل التجليد، الغرفة 12، كساحة قريبة وواضحة. تبقى الرفوف والكتب والرقوق المرسومة الأصلية حاضرة، ويُفتح الفراغ خلف جسم البطل والجرس. لا تُضاف قاعة بعيدة أو لوحة ضخمة جديدة.

## التكوين البصري

- الخلفية المعتمدة هي `assets/environments/paper_shadows/close_archive.png`، مع تهدئة طفيفة لألوانها داخل الغرفة 12. أصلها موثق في `assets/environments/paper_shadows/art_manifest.json`؛ لم تُولّد صورة بيئية جديدة.
- يستبدل `scripts/stage/m24_room_visuals.gd` عوارض المكابس الثلاثة والرفوف السوداء المتكررة خلف المواجهة. تُرسم آلتان ساكنتان عند x=755 وx=2690، خارج مساحة الجسم المركزية x=900..2400. الشريط العلوي مرفوع وثابت.
- يبقى منتصف القتال بلا قضيب متحرك أو لوح شاحب أو علامة أرضية. تقوم الرفوف الصغيرة عند أطراف الطريق بإبراز قرب المكان.
- توجد بركتا ضوء دافئ محدودتان قرب طرفي الساحة عند x=1050 وx=2230. تبقى مصابيح الاستراحات والقراءة خارج بوابتي القتال؛ عدد مصادر الغرفة الثابتة ستة، ولا تُضاف إضاءة عامة ساطعة.
- يترك `scripts/stage/m24_foreground.gd` الكتب الأمامية أسفل حافة الأرض بـ11 وحدة على الأقل. تصبح طيات أعلى الشاشة صغيرة، وتُحذف الأشكال الجانبية الطويلة التي كانت قد تعترض الجسم أو قفزة الجرس.

## حدود الدمج

يرث المرئي الجديد `m23_room_visuals.gd`، وتقتصر تجاوزاته على الغرفة 12. يستبدله ملف عالم M24 بعد إضافة مقعدَي الاستراحة وقبل إنشاء حارس الجرس. بقية الغرف تتبع مرئياتها الموروثة.

لا يحتوي المرئي أو الديكور الأمامي الجديد على جسم اصطدام أو منطقة ضرر أو ساعة هجوم. يتولى عالم M24 إفراغ `data.hazards` في نسخة الغرفة 12 وحدها، لأن مستطيلات المكابس القديمة كانت `(1050,980,180,280)` و`(1730,980,180,280)` و`(2410,980,180,280)`؛ الأولان داخل القتال والثالث يعبر البوابة والاستراحة اليمنى. لا تتغير الأعلام أو مقابض الممرات أو صفحات القراءة أو منصاتها الأصلية.

الأرض عند y=1260. تبقى ساحة القتال `Rect2(900,940,1500,320)`، والبوابتان عند x=860 وx=2440، والاستراحتان عند x=556 وx=2540. لا يضيف هذا العمل شخصية أو عدوًا أو زعيمًا في الغرفة 14؛ حجز مواجهتها المستقبلية مسؤولية العالم.

## تحقق محدود ونزيه

الأداة `tools/capture_m24_environment.gd` تُشغّل مشهد الجرس الأصلي داخل Godot 4.7.2 برسم GL Compatibility. تُثبّت موضعي البطل `(1360,1260)` والجرس `(1850,1260)`، والكاميرا `(1650,1010)` بتقريب 0.84، بغرض مقارنة البيئة فقط. لا تمثل الصور قتالًا متصلًا أو انتصارًا.

- `previews/m24/20_arena_before.jpg`: إعادة بناء قائمة المكابس المرئية الموروثة فقط، مع تعطيل فيزياء الشخصيتين. لا تعيد الصورة تشغيل ضرر المكابس في العالم.
- `previews/m24/21_arena_after.jpg`: المشهد نفسه والمواضع نفسها بعد استبدال طبقة البيئة.
- نجح 24 فحصًا: ثبات تعريفات المنصات والأشياء، غياب أجسام اصطدام جديدة، بقاء الآلتين خارج فراغ الجسم، سلامة حافة الديكور الأمامي، واختبارات أشعة فعلية لدعم الأرض وفراغ الجسم عند x=620 و960 و1200 و1500 و1850 و2200 و2340 و2604.
- للغرفة منصتان فعليتان كما في التعريف الأصلي: الأرض ورف القراءة قرب الطرف الأيمن. لا تشمل هذه الجولة إعادة فحص الغرف الخمس عشرة أو اختبار الموازنة القتالية.

التقرير المحفوظ لهذه الجولة هو `docs/M24_ENVIRONMENT_REPORT.json`. تكتب الأداة كل تشغيل جديد إلى `user://m24_environment_report.json`. لإعادة الالتقاط من مساحة العمل:

```bash
DISPLAY=:95 XDG_DATA_HOME=/workspace/work/m24_environment/data /workspace/tools/godot4.7.2 --path /workspace/-2d --rendering-method gl_compatibility --audio-driver Dummy --script res://tools/capture_m24_environment.gd
```
