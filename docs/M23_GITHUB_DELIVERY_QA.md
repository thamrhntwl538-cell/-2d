# تحقق تنزيل M23 من GitHub

نُزّلت حزمة المشروع المنشورة عند الالتزام `1738ddc87f833ddad25b94f9ec6aec2e8ee37158`، وفُكّت خارج مجلد العمل مع ذاكرة استيراد جديدة تمامًا.

- الحجم **245,484,353 بايت**، وعدد الملفات **1740**. نجح فحص CRC لكل عناصر ZIP، وطابقت جميع الملفات بصمات Git دون ملفات ناقصة أو مختلفة.
- بقي أطلس البطل المعتمد مطابقًا تمامًا لبصمته الأصلية.
- استيراد أول كامل في **Godot 4.7.2 Standard** خرج بنجاح دون أخطاء سكربت أو استيراد.
- تشغيل رسومي أصلي للنسخة المحمّلة نجح في **15 فحصًا**: مشهد F5 الصحيح، البطل الجديد، السعة والصحة الابتدائية، أصوات الشخصيتين، دخول الساحة بإدخالات فعلية، مواجهة البوس للبطل، والموسيقى والتحذير الأول من الذكاء الفعلي. لا أخطاء تشغيل أو تسرب موارد؛ تحذير V-Sync من الشاشة الافتراضية فقط.

أول تشخيص للفحص أخذ العينة في وقفة الانتظار الطبيعية بعد المقدمة؛ عُدّل الفحص لينتظر النمط الأول بدل حصر حالات مسموحة لا تتضمن تلك الوقفة. لم يُعدّل المشروع بسبب هذا التشخيص. التقرير الآلي يحتفظ بهذا الفرق بوضوح.

هذه مراجعة للحزمة والبداية الأصلية، وليست إعادة لاجتياز العالم كله. القتال الكامل 48 HP وفحوصه 96/96 موثقة في [M23_QA](M23_QA.md). أضيف هذا التقرير وأداة إعادة التحقق في متابعة توثيقية؛ كود اللعب والأصول يظلان مطابقين للالتزام المختبر أعلاه.

لإعادة فحص البداية استخدم مجلد بيانات منفصلًا مع `tools/test_m23_download_smoke.gd` على شاشة رسومية. يجب استيراد المشروع أولًا. التفاصيل والبصمات في [M23_GITHUB_DELIVERY_QA.json](M23_GITHUB_DELIVERY_QA.json).
