# اعتماد تصميم العالم الأول

اعتمد المستخدم الحزمة بتاريخ **2026-10-22** بقوله: **«ممتاز اعتمدها»**.

المرجع المعتمد: حزمة المكتبة المتحوّلة ذات15منطقة المنشورة في الالتزام `02c2b2a21ce0eecc820522febff12e6c088ae171`، وتشمل الخريطة وصور المناطق ودليل الألغاز والمواصفات.

- اتجاه D وهوية البيئة وصور المناطق01–15.
- المسار الرئيسي والفرع الاختياري، وأربعة اختصارات، وأربع استراحات وستة أسرار.
- ثلاثة ألغاز رئيسية واثنان اختياريان، مع حلول واختصارات محفوظة.
- يغلق العالم الأول بعد مغادرته عبر اختيار صريح قابل للإلغاء قبل العبور.
- العربية والإنجليزية مع خيار تبديل.
- صاحب الشعلة السوداء ظل مؤقت؛ تصميم شخصيته النهائي مؤجل.
- سبعة أنواع أعداء وزعيم مستقل كمواقع محجوزة في التصميم؛ أولوية العمل للبيئة والمسارات والألغاز أولًا، ثم الأعداء بعد نجاح البيئة.
- الاحتفاظ بتصميم البطل وألوانه ونسبه وحركة جريه المعتمدة.

حالة الاعتماد: **تصميم معتمد للتنفيذ**. تبقى مقاسات القفز والمنصات والتصادم والإضاءة والتوقيت قابلة للضبط أثناء اختبار البطل الفعلي في Godot. هذا السجل يثبت قرار التصميم؛ لا يسجل تنفيذ البيئة الجديدة أو تشغيلها داخل المحرك.
