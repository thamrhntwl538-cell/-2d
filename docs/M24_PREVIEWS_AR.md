# معاينات حارس الجرس M24

هذه الصفحة تميّز عينات مراجعة الرسم عن التسجيل الفعلي للعبة. تُنشر الصور والفيديو في فرع المعاينات، ويشير رابط GitHub الخام المثبّت برقم التزام إلى النسخة نفسها دائمًا.

لا تبرهن صور الرسم والبيئة على نجاح القتال أو عبور المسار. التسجيل الفعلي يُنتَج بعد تثبيت الرسم والصوت والحركة، وتأتي لقطات القتال فيه من مدخلات الحركة والقفز والسيف والتعويذة نفسها. الصوت المسجّل هو مزيج اللعبة الأصلي من Godot، دون استبداله بمسار خارجي.

الروابط المنشورة سابقًا بأرقام `01`–`06` كانت تعرض النموذج الأولي السابق للجرس والرجلين. الروابط الجديدة في هذه الصفحة هي المعتمدة للمراجعة؛ الأسماء الجديدة تمنع خلط الصور المحفوظة مؤقتًا بالإصدار النهائي.

لإعادة التقاط عينات الرسم محليًا:

```bash
DISPLAY=:95 /workspace/tools/godot4.7.2 --path /workspace/-2d \
  --audio-driver Dummy --resolution 1280x720 \
  --script res://tools/capture_m24_character.gd
```

البيانات المصاحبة: `previews/m24/character_capture_metadata.json` و`previews/m24/demo_capture_metadata.json`. تسجل نسخة المحرك، أبعاد الإطار، ونطاق العينة وحدود ما تثبته.
