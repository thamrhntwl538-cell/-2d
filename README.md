# LAST LECTURE — M27: مواجهة أمين الأرشيف

أمين الأرشيف يقترب الآن إلى مدى مناسب لكل هجمة قبل تنفيذها، وتلتقط الأوراق السريعة تماسها مع البطل بين الإطارات. تبقى مهلة الحماية بعد الإصابة **ثانية كاملة** وفق اختيار المستخدم. للمواجهة قاعة خاصة برفوف قريبة وخزانة فهرس مختومة وإنارة كهرمانية، تستقبل ضوء فانوس البطل.

## التشغيل

1. نزّل ZIP وفك الضغط، واحتفظ **بالمجلد كاملًا**.
2. في **Godot 4.7.2 Standard** اختر **Import** وافتح `project.godot` في جذر المجلد، وانتظر اكتمال الاستيراد.
3. اضغط **F5** لفتح استوديو الحركات، ثم **Enter** أو **A** في يد التحكم لدخول المواجهة.
4. اقترب من أمين الأرشيف: يعلو غناؤه من مكانه ثم يتوقف عند بدء القتال. **R** يعيد المحاولة، و**Esc** يعيدك إلى الاستوديو.

المشهد الافتراضي: `scenes/minibosses/archivist_reference_m26.tscn`. مشهد المواجهة: `scenes/minibosses/archivist_trial_m26.tscn`، ويمكن فتحه مباشرة واستخدام **F6**. تحتفظ أسماء المشاهد برقم M26؛ نسخة المشروع الحالية M27.

## ما تغير في المواجهة

- للمطرقة والضربات القريبة مدى بدء خاص؛ يواصل الأمين الاقتراب إذا تحرك البطل بعيدًا، بدل انتهاء المشي مبكرًا وتنفيذ الضربة من مسافة لا تصل إليه. يُثبت الاتجاه عند بدء الهجمة الفعلية، ويمكن تفاديها بعدها بالحركة.
- يُترك حيز للاندفاع المرسوم في الكومبو وقلب الصفحة قبل بدء الحركة، لتجنب القفز المفاجئ إلى موضع آخر عند حواف الساحة.
- لكل ورقة في كل دفعة مسار تماس مستقل. إذا تفاديت الدفعة الأولى، تستطيع الثانية أو الثالثة إصابتك عند ملامستك. أما إذا أصابتك الأولى، فمرور أوراق أخرى خلال **ثانية الحماية** دون ضرر سلوك مقصود؛ لم تُختصر المهلة ولم تُؤخر الدفعات.
- صُممت قاعة الخزانة المختومة للمواجهة، مع بقاء مساحة القتال واضحة وخلفية تتأثر بضوء البطل.

## التحكم في المواجهة

| الفعل | الكيبورد | يد التحكم |
| --- | --- | --- |
| الحركة والتوجيه | A/D أو الأسهم، وW/S للتوجيه | العصا اليسرى أو D-pad |
| القفز | Space | A |
| ضربة السيف | J | X |
| الداش | K | RB |
| التقنية | L | B |
| العلاج بالضغط المطوّل | H | Y |
| الإيقاف والاستئناف | P | Start |
| إعادة المحاولة | R | Y أثناء الإيقاف أو بعد الموت أو الفوز |
| العودة إلى الاستوديو | Esc | Back |

أثناء القتال تبقى مؤشرات البطل أعلى اليسار فقط. البطل بلا صوت بشري، وتبقى مؤثرات سيفه وحركته المعتمدة.

## استوديو الحركات

اختر الحركة من القائمة أو **↑/↓**، وراجع الإطارات باستخدام **←/→**. **1/2** يبدّل الطور، و**F** يعكس الاتجاه، و**Space** يوقف العرض، و**H** يعرض مستطيلات المصدر، و**S** يبدّل الصوت، و**R** يبدّل الغضب، و**C** يشغّل التسلسل. **R داخل المواجهة يعيد المحاولة**.

في يد التحكم: **LB/RB** لاختيار الحركة، و**Y** للطور، و**X** لعكس الاتجاه، و**Start** للإيقاف، و**A** لدخول المواجهة. من الاستوديو اضغط **B** لفتح معاينة حارس الجرس السابقة، ثم **Enter/A** لتجربة قتاله.

## الرسم ونطاق النسخة

تستمر النسخة باستخدام رسم المستخدم نفسه: **18 حركة، و 29 تسلسلًا بحسب الطور، و 1505 إطارات** محفوظة البكسلات، مع امتدادات المؤثرات المستعادة من HTML الأصلي. تبقى مؤثرات الصوت الـ 43، والغناء المكاني، والتحذيرات المعتمدة، ورسم البطل وحارس الجرس محفوظة.

الطور الأول يضم ست هجمات، والطور الثاني يحتفظ بها ويضيف ستًا. تبقى سرعة هجمات الطور الثاني **1.15×** والغضب تحت 15% من الصحة **1.3× إضافية**. الصحة 48، وسرعة المشي 105 بكسلات/ثانية، وترتيب الهجمات والتحول عند نصف الصحة إعدادات ربط داخل Godot؛ HTML يحدد الرسم والحركات، ولا يحتوي مواجهة كاملة بذكائها وصحتها.

هذه مواجهة مستقلة للاختبار، لم توضع بعد في خريطة الغرف الخمس عشرة، ولا تمنح مكافأة دائمة أو تعدّل تقدم المكتبة. مشهد المكتبة السابق: `scenes/stage_01/folding_library_m24.tscn`.
